# Prece Digital - Documentación

Carpeta destinada a centralizar la documentación técnica y funcional de **Prece Digital**.

Aquí se documentan decisiones de arquitectura, alcance del sistema, funcionamiento de módulos, API, base de datos y procedimientos generales del proyecto.

## Estado de la documentación

La documentación de **Prece Digital** se da por finalizada para esta entrega.

- [Documento final en PDF](Prece_Digital1.pdf).
- [Documento final editable en Word](Prece_Digital.docx).
- [Manuales de usuario](Manual%20de%20Usuario/).

Las observaciones y los pendientes registrados en los documentos se conservan para su seguimiento.

## Forma de trabajo

Crear **Pull Request hacia `main`**.

## Relación con Backend y Frontend

El equipo de Documentación puede consultar las carpetas de Backend y Frontend para mantener la documentación actualizada.

Cuando Backend o Frontend incorporen funcionalidades nuevas, la documentación correspondiente debe actualizarse cuando sea necesario.

## Reglas básicas

- No trabajar directamente sobre `main`.
- Mantener la documentación actualizada.
- Usar nombres claros para archivos y carpetas.
- Evitar duplicar documentación innecesariamente.
- Utilizar Pull Requests.
- Documentar cambios relevantes de arquitectura, API o funcionamiento.
